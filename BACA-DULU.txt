KALY DENAH SERVICE - CARA MEMASANG (GitHub)
===========================================

Aplikasi terpisah untuk tim service: mencatat tamu datang, tamu pulang, dan catatan
per meja di denah Kaly Eatery (42 meja bawaan, bisa ditambah lewat Atur meja).
Sejak 1 Nov 2026 SEPENUHNYA DI GITHUB, tanpa Netlify:
  - Halaman  : GitHub Pages dari repository publik  choirulefendy-blip/denahkalyservice
  - Data tamu: repository PRIVAT                    choirulefendy-blip/denahkalyservice-data
               (setiap catatan = satu file JSON, setiap perubahan tercatat sebagai commit)
Tidak memakai Supabase dan tidak mengubah data Kaly Ops.

1. TERBITKAN HALAMAN (sekali)
   GitHub > repository denahkalyservice > Settings > Pages >
   Build and deployment > Source: GitHub Actions.
   Tunggu tab Actions selesai (centang hijau, 1-2 menit). Alamatnya:
     https://choirulefendy-blip.github.io/denahkalyservice/
   Setiap perubahan di folder public/ pada branch main terbit otomatis. Gratis.

2. BUAT REPOSITORY DATA (sekali)
   GitHub > New repository > nama: denahkalyservice-data > pilih PRIVATE >
   centang "Add a README file" > Create repository.
   WAJIB privat: berisi nama tamu & catatan. Aplikasi menolak repository publik.

3. BUAT KUNCI GITHUB (sekali)
   GitHub > foto profil > Settings > Developer settings > Personal access tokens >
   Fine-grained tokens > Generate new token:
   - Token name     : Denah Service
   - Expiration     : 1 tahun (catat tanggalnya; sebelum habis buat kunci baru)
   - Repository access: Only select repositories > denahkalyservice-data SAJA
   - Permissions > Repository permissions > Contents: Read and write
   Generate token > salin (diawali github_pat_). Simpan di tempat aman.

4. SAMBUNGKAN SETIAP TABLET/HP (sekali per perangkat, oleh admin)
   Buka alamat di langkah 1 > layar "Sambungkan perangkat":
   - Repository data: choirulefendy-blip/denahkalyservice-data
   - Kunci GitHub   : tempel kunci dari langkah 3
   Perangkat pertama lalu menampilkan "Siapkan Denah Service":
   - PIN staf  (4-8 angka) untuk tablet/HP service sehari-hari
   - PIN admin (4-8 angka) untuk Pengaturan, Atur meja, koreksi & hapus data
   - Nama petugas service, satu per baris
   Di Chrome: menu > Tambahkan ke layar utama, supaya terbuka seperti aplikasi.

5. PAKAI SEHARI-HARI
   Masukkan PIN staf > pilih nama petugas.
   - Tamu datang : ketuk meja kosong > jumlah tamu, nama, catatan > Catat tamu datang
   - Catatan     : ketuk meja terisi > tulis catatan atau ketuk label cepat
   - Pindah/gabung meja, ubah jumlah tamu: tombol di panel meja
   - Tamu pulang : tombol oranye Tamu pulang > meja kosong lagi
   - Riwayat     : semua kunjungan per tanggal + Unduh Excel (CSV)
   - ATUR MEJA (PIN admin): Denah > Atur meja. Ketuk tempat kosong untuk menambah
     meja, seret untuk memindah, ketuk meja untuk ubah/hapus, lalu Selesai.

KEAMANAN (PENTING)
   - Kunci GitHub hanya dimasukkan di perangkat, TIDAK PERNAH ditaruh di kode/repository.
   - Siapa pun yang memegang kunci itu bisa membaca & mengubah data tamu. PIN memisahkan
     peran staf/admin di aplikasi, tetapi tidak melindungi data dari pemegang kunci.
   - Tablet/HP hilang atau staf berhenti: hapus kuncinya di GitHub (Fine-grained tokens >
     Revoke), buat kunci baru (langkah 3), sambungkan ulang perangkat yang masih dipakai,
     lalu Pengaturan > Keluarkan semua perangkat.
   - Lupa PIN admin: buka repository denahkalyservice-data di GitHub > Add file >
     Create new file > nama: reset-pin.txt (isi bebas) > Commit. Buka aplikasi di
     perangkat yang sudah tersambung: muncul "Buat PIN baru". Daftar meja, petugas,
     dan riwayat tamu tetap.

BATAS GITHUB
   - 5.000 permintaan per jam untuk SEMUA perangkat yang memakai kunci yang sama.
     Sinkron tiap 30 detik: kira-kira 120 permintaan/jam per perangkat saat tidak ada
     perubahan, jadi aman untuk sekitar 10-20 perangkat. Biarkan "memperbarui setiap
     30 detik" di Pengaturan.
   - Bila muncul "Batas akses GitHub per jam habis", tunggu beberapa menit.

DATA & CADANGAN
   Semua data ada di repository denahkalyservice-data (folder v/ per tanggal,
   t/ penanda meja terisi, config.json pengaturan). Riwayat lengkap tersimpan sebagai
   commit. Unduh Excel (CSV) dari halaman Riwayat untuk laporan.
